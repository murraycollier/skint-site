Skint is designed to work with the keyboard. Most shortcuts work anywhere in the app, but the editing keys only apply while you're editing a cell or a new row.

## Search

| Key | What it does |
| --- | --- |
| `/` | Moves the cursor to the search box at the top of the sidebar. It doesn't work while you're typing in another field. |
| `↓` / `↑` | Moves through the search results. |
| `Enter` | Opens the highlighted result. |
| `Escape` | Clears the search and closes the results. |

## Editing a cell

Click any cell marked for editing (the cell shows a hover hint with the text "Click to edit"). Then:

| Key | What it does |
| --- | --- |
| `Enter` | Saves the change. |
| `Escape` | Cancels the change and keeps the old value. |
| `Tab` | Saves the change and moves to the next cell in the row. |
| `Shift` + `Tab` | Saves the change and moves to the previous cell in the row. |

For cells with a fixed set of choices, such as category, picking a choice saves it straight away.

## Adding a new row

When you choose **Add bill**, a new row opens at the top of the list:

| Key | What it does |
| --- | --- |
| `Enter` | Saves the new row. |
| `Escape` | Discards the new row. |

## Menus and dialogs

| Key | What it does |
| --- | --- |
| `Escape` | Closes a column menu. |
| `Escape` | Closes a dialog, such as a confirmation or an edit form. |
| `Escape` | Closes the mobile menu on small screens. |

## Tips

- Your browser's own shortcuts still work, such as `Cmd` or `Ctrl` with `F` to search the page, and `Cmd` or `Ctrl` with `+` and `-` to zoom.
- On a phone, use the bottom bar to move between pages.
