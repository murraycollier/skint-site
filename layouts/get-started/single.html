Setup guide

Set up Skint, step by step

No experience with computers' command line needed. You'll install one free app, copy and paste a few lines of text, and then open Skint in your web browser. Each step explains what it's doing and why.

  • About 15 minutes
  • Mac, Windows or Linux
  • No programming needed

Before you start

Skint is a web app that runs on your own computer or home server. To run it, you need Docker, a free app that runs programs like Skint in a safe, self-contained box. You'll also use the Terminal, a window where you type short instructions. Don't worry: you only copy and paste a few lines.

  • A Mac, a Windows PC, or a Linux computer that you can leave switched on
  • An internet connection for the first download
  • Your Expenditure spreadsheet, if you want to import existing figures
1

Install Docker

Docker is the app that runs Skint. Install it once, then leave it alone. Choose the option for your computer.

Mac or Windows

Docker Desktop

  1. Go to docker.com/products/docker-desktop and download the version for your computer.
  2. Open the file you downloaded and follow the installer. On Windows, if it asks you to turn on WSL 2, say yes and restart when asked.
  3. Open Docker Desktop from your Applications (Mac) or Start menu (Windows). Accept the terms and skip any sign-in prompts.
  4. Wait until the Docker whale icon in your menu bar or taskbar stops animating and says it's running.

Mac only

OrbStack (alternative)

  1. Download it from orbstack.dev and open it.
  2. Follow the setup. It works the same way as Docker Desktop for everything in this guide.

Linux

Docker Engine

On Ubuntu or Debian, run these in the Terminal (see step 2). Other Linux systems are covered in Docker's guide.

sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
sudo usermod -aG docker $USER

After the last line, log out and back in so the change takes effect.

2

Open the Terminal

The Terminal is a window where you type instructions to your computer. Open the one for your system:

Mac

Terminal

Press Command + Space, type Terminal, and press Enter. A window with a blinking cursor opens.

Windows

PowerShell

Press the Start key, type PowerShell, and press Enter. A blue or black window opens.

Linux

Terminal

Press Ctrl + Alt + T. On most desktops this opens the Terminal.

Each time you see a grey box below, copy the text in it (the Copy button in the top-right corner does this), click into the Terminal window, paste with Command + V (Mac) or Ctrl + V (Windows and Linux), and press Enter. Nothing happens until you press Enter.

Tip: the Terminal is fine to close once Skint is running. Skint keeps going in the background.
3

Download the setup files

Click the button below. Your browser saves a file called skint-setup.zip to your Downloads folder.

Download setup files

Now unzip it into a new folder called skint:

Mac

Double-click skint-setup.zip. A folder with the same name appears next to it. Rename that folder to skint, and move it to your Documents folder.

Windows

Right-click skint-setup.zip and choose Extract All. Rename the new folder to skint, and move it to your Documents folder.

Inside the folder you should see two files: docker-compose.yml and env.example.

4

Open the folder in the Terminal

The Terminal needs to be inside the skint folder, so it can find the files. The quickest way:

Mac

  1. Open the skint folder in Finder.
  2. In the Terminal, type cd (the letters c, d and a space).
  3. Drag the skint folder from Finder onto the Terminal window. Its path appears after cd.
  4. Press Enter.

Windows

  1. Open the skint folder in File Explorer.
  2. Click the grey address bar at the top, type powershell, and press Enter.
  3. A PowerShell window opens already inside the folder.

To check you're in the right place, type ls (Mac) or dir (Windows) and press Enter. You should see docker-compose.yml listed.

5

Make your settings file

Skint reads its settings from a file called .env. You make it by copying the example file. Paste this into the Terminal and press Enter:

Mac

cp env.example .env

Windows

copy env.example .env

Nothing visible happens, which is normal. A new file called .env is now in the folder.

Open the settings file and check it

  1. Open the skint folder in Finder (Mac) or File Explorer (Windows).
  2. Find the file called .env and open it in a plain text editor: TextEdit on Mac (choose Format → Make Plain Text first), or Notepad on Windows.
  3. You'll see a few lines. The most important one is ALLOWED_HOSTS. It should read localhost, which is correct for opening Skint on this computer. Leave the rest as it is for now.
  4. Save the file and close the editor.
Can't see .env? On a Mac, press Command + Shift + . in Finder to show hidden files. On Windows, in File Explorer open the View menu and tick Hidden items.
Want a password? Set APP_PASSWORD to any password you like, for example APP_PASSWORD=choose-a-long-password. Anyone opening Skint will then need to sign in. Once you set a password, everyone in the household also signs in with an authenticator app (step 9). Leave it empty to skip sign-in.
6

Start Skint

Make sure Docker Desktop is running (the whale icon has settled). Then paste this into the Terminal, in the skint folder, and press Enter:

docker compose up -d

The first time, Docker downloads Skint. This takes a minute or two, and you'll see lines of text scroll by. When it stops and you're back at a line with a cursor, Skint is running.

Running in the background. The -d means Skint runs quietly. You can close the Terminal, and Skint keeps running until you stop it.
7

Open Skint

Open your web browser (Safari, Chrome, Edge or Firefox), click the address bar at the top, paste this address and press Enter:

http://localhost:8080

The Skint dashboard opens. If it's blank or says the page can't be reached, wait another 30 seconds and refresh. Docker sometimes needs a moment after starting.

If you set a password in step 5, you'll see a sign-in screen first. Enter the username admin (or whatever you set as APP_USER) and your password, then follow step 9.

8

Load your figures

On the first visit the dashboard offers Import spreadsheet. Click it, choose your Expenditure.xlsx file, and Skint loads your bills and income.

Heads up: importing replaces everything Skint has stored. If you already have data, download a backup first from Settings → Download JSON.

Don't have a spreadsheet, or want to start fresh? Skip the import and add bills yourself from the Bills page.

9

Add the household

Add each person in Settings → People, so bills and income can be shared between you.

If you set a password in step 5, each person also needs two-step sign-in the first time they sign in:

  1. Install an authenticator app on a phone, such as Google Authenticator, Authy or Bitwarden.
  2. Sign in with the username and password. Skint shows a QR code.
  3. Scan the QR code with the authenticator app. It starts showing six-digit codes that change every 30 seconds.
  4. Type the current six-digit code into Skint.
  5. Skint then shows eight recovery codes. Write them down or save them somewhere safe. Each one works once, if you ever lose your phone.
Lost your phone? An admin can reset that person's two-step sign-in under Settings → People → Reset 2-step. They then set it up again at their next sign-in.

Everyday use

Stop Skint

In the Terminal, in the skint folder, type docker compose down and press Enter. Your data is kept.

Start it again

Make sure Docker Desktop is running, then type docker compose up -d and press Enter. Open http://localhost:8080 in your browser.

Update Skint

Open docker-compose.yml in your text editor. Find the line starting image:, change the number after skint: to the new version from the releases page, save, then type docker compose up -d.

If something goes wrong

"command not found" or "docker is not recognized"

Docker isn't installed or isn't running. Open Docker Desktop, wait for the whale to settle, then try again.

"Cannot connect to the Docker daemon"

Docker Desktop is closed. Open it and wait until it says it's running.

Browser says the page can't be reached

Wait 30 seconds and refresh. If it still fails, type docker compose ps in the Terminal. The status should say running or healthy.

"400 Bad Request" in the browser

The ALLOWED_HOSTS line in .env doesn't include localhost. Open .env, set the line to ALLOWED_HOSTS=localhost, save, then type docker compose up -d again.

"port is already allocated" or "address already in use"

Something else on your computer is using port 8080. Change "8080:8000" in docker-compose.yml to "8081:8000", save, and open http://localhost:8081 instead.

Still stuck?

Ask on Discord, or open an issue on GitHub and describe what you typed and what you saw.

Keep your data safe

Back up regularly

In Skint, go to Settings and choose Download JSON. Keep a copy somewhere other than this computer.

Don't delete the data

Never type docker compose down -v. The -v part deletes all your Skint data.

Going online

If you want to open Skint from other devices, set a password and put it behind HTTPS. See the advanced section below.

Advanced: behind a reverse proxy

Optional. Only read this if you already run Traefik or nginx on your server. Most people can skip it.

Skint listens on port 8000 inside its container. The default setup publishes that as port 8080. If you already run Traefik or nginx, put Skint on your proxy network instead and let the proxy handle HTTPS. Replace skint.example.com with your domain in each example.

Traefik

docker-compose.yml with Traefik labels

Assumes Traefik has a websecure entrypoint, a letsencrypt certificate resolver, and an external Docker network called proxy. Remove the ports section, because Traefik reaches Skint over the network.

services:
  skint:
    image: ghcr.io/murraycollier/skint:1.0.2
    container_name: skint
    restart: unless-stopped
    networks:
      - proxy
    environment:
      APP_USER: ${APP_USER:-admin}
      APP_PASSWORD: ${APP_PASSWORD:-}
      ALLOWED_HOSTS: skint.example.com
      MFA_REMEMBER_DAYS: ${MFA_REMEMBER_DAYS:-7}
    volumes:
      - skint-data:/data
    labels:
      - "traefik.enable=true"
      - "traefik.docker.network=proxy"
      - "traefik.http.routers.skint.rule=Host(`skint.example.com`)"
      - "traefik.http.routers.skint.entrypoints=websecure"
      - "traefik.http.routers.skint.tls.certresolver=letsencrypt"
      - "traefik.http.services.skint.loadbalancer.server.port=8000"

networks:
  proxy:
    external: true

volumes:
  skint-data:

nginx

docker-compose.yml with nginx in front

Skint and nginx share a private network. Skint publishes no port, so only nginx can reach it. Put your certificate and key where the paths in nginx.conf point.

services:
  skint:
    image: ghcr.io/murraycollier/skint:1.0.2
    container_name: skint
    restart: unless-stopped
    networks:
      - web
    environment:
      APP_USER: ${APP_USER:-admin}
      APP_PASSWORD: ${APP_PASSWORD:-}
      ALLOWED_HOSTS: skint.example.com
      MFA_REMEMBER_DAYS: ${MFA_REMEMBER_DAYS:-7}
    volumes:
      - skint-data:/data

  nginx:
    image: nginx:stable
    container_name: skint-nginx
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/conf.d/skint.conf:ro
      - ./certs:/etc/nginx/certs:ro
    networks:
      - web
    depends_on:
      - skint

networks:
  web:

volumes:
  skint-data:

nginx.conf

server {
    listen 80;
    server_name skint.example.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl;
    server_name skint.example.com;

    ssl_certificate     /etc/nginx/certs/fullchain.pem;
    ssl_certificate_key /etc/nginx/certs/privkey.pem;

    location / {
        proxy_pass http://skint:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
