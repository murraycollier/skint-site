Download

Get Skint, free.

Grab the app and the setup files, then run it with Docker Compose. Don't have Docker yet? Install it for macOS, Windows or Linux. The full guide is in the setup guide.

Everything you need skint.zip The app source, Dockerfile, requirements, docker-compose.yml and .env.example. About 85 KB.
  1. Unzip skint.zip into a new folder.
  2. Run cp .env.example .env, then edit it if you want a sign-in screen.
  3. Run docker compose up -d --build and open http://localhost:8080.

Self-hosted and private

Your money stays on your machine.

Skint runs as a single Docker container and keeps its data in one SQLite file on a volume you control. There are no third-party scripts, fonts or trackers in the app itself.

  • Optional sign-in screen, with a password you choose
  • Two-step sign-in with an authenticator app and eight single-use recovery codes
  • Restrict the app to your own domain names, so raw IP addresses are refused
  • Full JSON backups and an Excel export at any time
  • Runs behind Traefik or any HTTPS reverse proxy

Questions

Good to know

Is Skint free?

Yes. Download it and run it on your own machine at no cost. A coffee is always welcome but never required.

Do I need to connect my bank?

No. Skint doesn't connect to any bank. You enter bills yourself or import your spreadsheet, so nothing needs access to your accounts.

Where is my data kept?

In a single SQLite file on a Docker volume on your server. The app makes no outside requests. You can download a full JSON backup at any time.

Can more than one person use it?

Yes. Everyone in the household has their own sign-in and shares the same figures. If someone loses their phone, an admin can reset their two-step sign-in.

What do I need to run it?

A machine that can run Docker and Docker Compose. Put it behind HTTPS if you open it beyond your own network.
